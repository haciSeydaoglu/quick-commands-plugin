# Run IDE

Plugin'i test etmek için geliştirme IDE'sini başlat.

## Komut

```bash
./gradlew runIde
```

## Not

Bu komut yeni bir IntelliJ IDEA örneği açar ve plugin otomatik olarak yüklü gelir. Test için kullan.
